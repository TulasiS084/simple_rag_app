# MERN Stack Todo App

## Overview
A simple Todo application built with MongoDB, Express, React, Node.js.

## Setup

### Prerequisites
- Node.js 20+
- MongoDB

### Backend Setup
```bash
cd backend
npm install
cp ../.env.example .env
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### Docker (Optional)
```bash
docker-compose up --build
```
