# Frontend Development Skill

Guidelines for modern, responsive, and reliable web frontends.

## Standards

1. **Contract Mocking & Decoupling**:
   - Consume endpoints defined in `api-contract.json`. Use lightweight mocking during early development.

2. **Component Architecture & Clean State**:
   - Separate presentational components from stateful containers.
   - Maintain clean, predictable state management.

3. **Accessibility & Cross-Platform UI**:
   - Use semantic HTML, responsive viewport scaling, and keyboard navigation.
