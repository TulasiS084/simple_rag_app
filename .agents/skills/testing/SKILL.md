# Testing Skill

Testing strategies for verifying software components in multi-agent environments.

## Testing Layers

1. **Unit Tests**:
   - Fast, isolated checks of business logic functions and data transforms.
2. **Integration Tests**:
   - Verify HTTP routes, database transactions, and component interactions.
3. **End-to-End (E2E) & Browser Tests**:
   - Automated user journey tests verifying visual DOM elements, flows, and API integration.
4. **Reporting**:
   - Formulate structured output adhering to `qa-report.schema.json`.
