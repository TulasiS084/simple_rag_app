# Security Review Skill

Security procedures and risk assessment standards.

## Audit Areas

1. **Secret & Key Management**:
   - Verify zero credentials, tokens, or private certificates exist in code or git history.
2. **OWASP Top 10 Checks**:
   - Injection, broken authentication, sensitive data exposure, security misconfigurations, and broken access controls.
3. **Dependency Scanning**:
   - Audit external dependencies for known CVEs.
